# Products

[You can get all products by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/products
```

[method: GET]

[You can get a specific product by hitting the below endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/products/2
```
- where 2 is the post id

[method: GET]

[You can add a new products by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/products
```

[method: POST]

[and add the product object inside the body of the API request like this ⬇️⬇️]

```
body: {
        title: "Your product title",
        body: "your product body"
    },
```

[You can add a new product by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/product/3
```
- where 3 is the product id

[method: PUT]

[and add the product object inside the body of the API request like this ⬇️⬇️]

```
body: {
        title: "Your product title",
        body: "your product body"
    },
```

[You can get all categories by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/products/categories
```

[method: GET]

[You can get all products that has specific category by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/products/category/electronics
```

- where electronics is product category

[method: GET]
