# Posts

[You can get all posts by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/posts
```

[method: GET]

[You can get a specific post by hitting the below endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/posts/10
```
- where id is the post id

[method: GET]

[You can add a new post by hitting the below API endpoint ⬇️⬇️]

```
random-api-app.netlify.app/api/posts
```

[method: POST]

[and add the post object inside the body of the API request like this ⬇️⬇️]

```
body: {
        title: "Your post title",
        body: "your post body"
    },
```
